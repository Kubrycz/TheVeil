# THE VEIL

## Current stack
- React, TypeScript, Vite, Three.js, and React Three Fiber.
- Camera movement currently follows native page scroll; add GSAP and ScrollTrigger when more complex scene transitions need them.
- The current prototype is a procedural portal scene with shader animation and three scroll chapters. No external models, textures, or audio are in use.

## Working style
- Build the project in small steps, one main task at a time.
- Explain the goal and reason briefly; help the learner write and understand the code.
- Prefer clear, typed code and avoid unnecessary files, abstractions, or dependencies.
- Prioritize the art direction, real browser behavior, responsive performance, and reduced-motion comfort.
- Preserve existing project files, including `.vscode/symbols.json`.
